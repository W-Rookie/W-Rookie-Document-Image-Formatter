# W-Rookie for Windows

## 지원 범위

- Windows 10/11
- DOCX, HWP, HWPX
- Python 3.10 이상
- HWP/HWPX 처리 시 한컴오피스 한/글 필요

## 최초 설치

1. ZIP을 마우스 오른쪽 버튼으로 누르고 **모두 압축 풀기**를 선택합니다.
2. Python 설치 시 가능하면 `Add python.exe to PATH`를 체크합니다.
3. 압축을 푼 폴더에서 `setup.bat`을 실행합니다.
4. `[1/4]`부터 `[4/4]`까지 기다립니다.
5. `Setup completed successfully.`가 나오면 아무 키나 눌러 닫습니다.
6. `run.bat`을 실행합니다.

CMD 창이 닫히고 `W-Rookie · 문서 사진 자동 편집` 창이 남으면 정상입니다.
다음 실행부터는 `run.bat`만 사용합니다.

## 문서 처리

1. **파일 추가** 또는 **폴더 추가**로 문서를 선택합니다.
2. **스마트 중앙 정렬(권장)**을 선택합니다.
3. 크기를 바꾸려면 **크기 조절 사용**을 체크하고 가로·세로 수치와 `mm/cm` 단위를 입력합니다.
4. 비례 확대·축소는 **원본 비율 유지**를 켭니다. 정확한 두 수치가 필요하면 끕니다.
5. 테두리 `1.0pt`, 검정색을 확인합니다.
6. **새 파일로 저장(원본 보존)**을 선택합니다.
7. **작업 시작**을 누릅니다.
8. 원본 옆의 `_사진정렬` 결과 파일을 확인합니다.

예: 가로 `50`, 세로 `30`, 단위 `mm`, 비율 유지 해제는 사진을 정확히 50×30mm로 맞춥니다. 비율 유지를 켜면 50×30mm 박스 안에 사진 전체가 들어가도록 맞춥니다.

DOCX는 별도 Office 프로그램 없이 처리됩니다. HWP/HWPX는 한컴오피스
한/글이 설치된 Windows에서만 처리됩니다.

## 오류 기록

- 설치 오류: `setup-error.log`
- GUI 시작 오류: `w-rookie-error.log`
